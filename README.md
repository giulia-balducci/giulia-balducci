# Hi, I'm Giulia 👋

I'm a Materials Chemistry PhD applying deep scientific expertise to data science, with a focus on climate, energy, and environmental data.

My background is in solid-state chemistry and hydrogen storage materials. During my PhD, I achieved a reduction of nearly 100 K in hydrogen release onset temperature through nanostructuring of LiOH-MgH₂ systems. I studied three hydride-hydroxide systems and proposed their dehydrogenation mechanisms from thermogravimetric analysis (TG-DTA-MS) and ex-situ PXRD, and followed the Mg(OH)₂-LiH reaction in situ with neutron diffraction at ISIS Rutherford Appleton Laboratory, analysed by Rietveld refinement.

What has always driven me is the analytical side: designing experiments, finding patterns in complex data, and communicating results clearly. That's what I do now, with Python instead of lab glassware.

## 🗂️ Projects

| Project | Description | Tools |
|---|---|---|
| ⚗️ [Hydride Property Prediction](https://github.com/giulia-balducci/hydride-property-prediction) | Materials informatics applied to metal hydride systems. A feature built from domain knowledge (composition-weighted formation energy) lifted a Random Forest from R² 0.495 to 0.765 for hydrogen storage capacity. The desorption temperature model (test R²=0.700, RMSE=87 °C) is documented as limited by its small training set | Python, scikit-learn, SHAP, chemparse |
| 🌊 [Marine Heatwave Detection (Mediterranean Sea)](https://github.com/giulia-balducci/marine-heatwave-detection) | SQL/DuckDB pipeline, with an Xarray step for satellite SST data, detecting 253,145 marine heatwave events (2016-2026) in the NW Mediterranean using the Hobday et al. methodology, implemented from scratch with window functions and gaps-and-islands logic. Two extreme events (46 and 161 days) verified against raw satellite data | SQL, DuckDB, Python, xarray |
| 🪸 [Coral Bleaching Risk Prediction](https://github.com/giulia-balducci/coral-bleaching-risk-analysis) | End-to-end ML pipeline predicting Atlantic coral bleaching risk from 40 years of oceanographic data. Random Forest optimised for recall (0.82 on test set). First deployed on AWS SageMaker (endpoint since decommissioned to avoid costs), the [live Streamlit dashboard](https://coral-bleaching-risk-analysis.streamlit.app) now runs local inference | Python, scikit-learn, SHAP, AWS SageMaker, Streamlit |
| 🌿 [Greenwashing Detection in Reef-Safe Sunscreen Claims](https://github.com/giulia-balducci/greenwashing-nlp-analysis) | NLP project combining RoBERTa sentiment analysis and VADER, anchored by the ACCC vs. Edgewell regulatory case. The dataset is 8 real documents plus 260 synthetic ones, so results are demonstrative. [Live dashboard](https://greenwashing-nlp-analysis.streamlit.app) | Python, RoBERTa, VADER, spaCy, Streamlit |
| 🌡️ [Land Temperature Trends (1850-2015)](https://github.com/giulia-balducci/land-temperature-trends-1850-2015) | Exploratory analysis and regression modelling of global land surface temperatures, asymmetric warming patterns and greenhouse effect signature | Python, pandas, seaborn, numpy |
